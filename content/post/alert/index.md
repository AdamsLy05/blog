早上打开手机，看到一条告警：

> 异常登录 - ECS 在非常用地登录

时间、IP、账号都列出来了。第一反应是：**有人进来了。**

---

## 先别慌，先看证据

告警里给了一条登录记录：某 IP、端口 22、用户 root、时间 09:32。

我要确认的只有一件事：**这次登录用的是不是我的钥匙。**

SSH 的公钥登录会留指纹。查一眼：

```sh
grep 'Accepted publickey' /var/log/auth.log | tail -5
```

结果里，09:30 那次登录的指纹是：

```
ED25519 SHA256:RBDqOKmRPIgxlWjssSwniXaEQ/3K4LWeJ03I1CX5pjw
```

再对一下服务器上唯一授权的那把公钥：

```sh
ssh-keygen -lf ~/.ssh/authorized_keys
```

**一模一样。**

## 那为什么会报"非常用地"

我的 IP 从 `111.183.145.139` 变成了 `111.183.148.74`。

查一下归属：

- 两个都是湖北武汉
- 都是中国电信
- **同一个自治域 AS131285（湖北 5G）**

只是移动网络重新分配了地址段。手机换基站、开关飞行模式、Wi-Fi 切 5G，都会这样。

安全中心是靠"登录位置基线"判断的，IP 段一变就触发。**这是它的正常工作方式，不是故障。**

## 顺手查的三件事

既然是虚惊，那就顺便把该看的看完：

1. **密码登录还开着吗**——之前关过，`sshd -T` 确认是 `no`
2. **有没有多余的账号**——只有一个 `admin`，密码是锁的，从没登录过
3. **cron 有没有被动过**——只有系统自带的两个

都没有异常。日志里倒是有一条扫描器在 05:16 试了个用户名——这种每天都在发生，密码登录关了就不用管。

## 学到的判断方法

以后再看到"异常登录"，我不看 IP 了，只看三样：

1. **公钥指纹**——是不是你那把
2. **登录方式**——`publickey` 还是 `password`（后者才是真问题）
3. **登录之后干了什么**——有没有新建用户、改 cron、开端口

IP 属于最不可靠的证据：它每天都在变，还是别人分配给你的。

## 一个小结

告警本身没错，它确实看到了一次"从没见过的位置"的登录。

是我的判断错了——我看到"异常"两个字就紧张，而不是先去找那个唯一的、决定性的证据。

**安全这件事，怕的不是告警多，是分不清哪条该怕。**
