早上打开手机，看到安全中心一条告警：

> 异常登录 - ECS 在非常用地登录

时间、IP、账号都列着。先说结论：是我自己的手机，虚惊一场。下面是查的过程——结论没什么用，方法有用。

## 要确认的只有一件事

告警给了登录记录：IP、22 端口、root、09:32。

需要确认的是这次登录用的是不是我这把钥匙。SSH 公钥登录会留指纹：

```sh
grep 'Accepted publickey' /var/log/auth.log | tail -5
```

09:30 那条记录的指纹是：

```
ED25519 SHA256:RBDqOKmRPIgxlWjssSwniXaEQ/3K4LWeJ03I1CX5pjw
```

再对一下服务器上唯一授权的那把：

```sh
ssh-keygen -lf ~/.ssh/authorized_keys
```

两者一致。

## 为什么被判成异地

IP 从 `111.183.145.139` 变成了 `111.183.148.74`。

查归属：都是湖北武汉、都是中国电信、同一个自治域 `AS131285`（湖北 5G）。只是移动网络重新分配了地址段——换基站、开关飞行模式、Wi-Fi 切 5G 都会这样。

安全中心按「登录位置基线」判断，IP 段一变就触发。这是它的正常工作方式，不是故障。

## 顺手核对了三件事

1. **密码登录**：`sshd -T` 确认是 `no`
2. **账号**：只有 `admin`，密码是锁的，从没登录过
3. **cron**：只有系统自带的两个

日志里还有一条 05:16 的扫描器在试用户名。这种每天都有，密码登录关着就不用管。

## 以后再看到这类告警

不看 IP，按顺序看三样：

1. **公钥指纹**是不是我这把
2. **登录方式**是 `publickey` 还是 `password`——后者才是真问题
3. **登录之后做了什么**：有没有新建用户、改 cron、开端口

IP 反而不重要：它是运营商分配的，天天在变。

告警本身没有错，它确实看到了一次没见过的位置。是我一开始把「异常」两个字当成了结论。

*2026-11-03，核对完，虚惊一场。*
